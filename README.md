\# DesarrolloMovil



Proyecto integrador de la materia \*\*Desarrollo Móvil Nativo\*\*, desarrollado para la plataforma Android utilizando Kotlin.



\## Ficha técnica



| Elemento | Información |

|---|---|

| IDE | Android Studio Quail 3 |

| Versión de Android Studio | 2026.1.3 |

| Lenguaje de programación | Kotlin |

| Versión de Kotlin | 2.2.10 |

| Plataforma | Android |

| Compile SDK | Android API 37 |

| Runtime / JDK | OpenJDK 25.0.2 |

| Sistema operativo | Windows 11 |

| Sistema de construcción | Gradle |

| Gestión de dependencias | Gradle Kotlin DSL |

| Control de versiones | Git |

| Repositorio remoto | GitHub |



\## Estructura del proyecto



El proyecto utiliza una estructura organizada para separar las responsabilidades de sus diferentes componentes y facilitar su mantenimiento y desarrollo.
